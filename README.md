# CC:Tweaked-Projekt (Starter)

1. Diesen Ordner in VS Code öffnen (Datei -> Ordner öffnen).
2. Cline installieren und mit einem Modell verbinden (siehe Guide).
3. In `.clinerules/01-projekt.md` den Abschnitt "Meine Base" ausfüllen.
4. Eigene Skripte nach `programme/<rolle>/` legen, gemeinsame Module nach `lib/`.
5. In `update.lua` die Zeile mit BASE auf dein GitHub-Repo ändern (nur nötig bei Weg 2).
6. Cline als erste Aufgabe die "erste Aufgabe" aus dem Guide geben.

Keine Passwörter oder API-Schlüssel in dieses Projekt schreiben.
